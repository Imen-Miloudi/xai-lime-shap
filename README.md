# Explainable AI: LIME vs SHAP

> Master 1 MAS Data Science — Aix-Marseille University  
> Study of explainability methods for black-box machine learning models

## Overview

Machine learning models such as Random Forest and XGBoost can achieve strong predictive performance while remaining difficult to interpret.

This project explores **Explainable Artificial Intelligence (XAI)** through a theoretical and experimental study of two major explanation methods:

- **LIME** — Local Interpretable Model-agnostic Explanations
- **SHAP** — SHapley Additive exPlanations

The objective was not only to apply these methods, but also to investigate the **reliability, stability and interpretability of the explanations they provide**.

The experiments were conducted on three different datasets representing different application contexts:

- 🚢 **Titanic** — survival prediction
- ⚖️ **COMPAS** — recidivism prediction and algorithmic bias
- 🧬 **Breast Cancer** — malignant vs benign tumor classification

---

## Research Questions

The project focuses on several questions:

- How can black-box machine learning predictions be explained?
- How do LIME and SHAP differ in their approach to explainability?
- How stable are the explanations generated by LIME?
- How does the choice of parameters affect LIME explanations?
- Can local explanations be aggregated to provide global insights?
- Which method is better suited to critical applications requiring reliable and reproducible explanations?

---

## Methods

### LIME

LIME explains an individual prediction by generating perturbed samples around the observation and fitting an interpretable local surrogate model.

In this project, LIME was used to:

- generate local explanations for individual predictions;
- analyse feature contributions;
- investigate feature interactions;
- aggregate local explanations to study global patterns;
- analyse the effect of the sampling process and `kernel_width` on explanation stability.

### SHAP

SHAP is based on Shapley values from cooperative game theory.

The project mainly uses **TreeSHAP**, which is specifically designed for tree-based models.

SHAP was used to:

- explain individual predictions;
- analyse global feature importance;
- study feature dependence and interactions;
- compare local and global explanations;
- evaluate the consistency and reproducibility of explanations.

## Experimental Setup

### 1. Titanic

A Random Forest classifier was trained to predict passenger survival.

LIME was used to study:

- individual predictions;
- the influence of **Sex** and **Pclass**;
- interactions between passenger characteristics;
- correlations between feature values and LIME weights.

SHAP was then used to provide both local and global explanations of the same model.

---

### 2. COMPAS

The COMPAS dataset was used to study explainability in a **high-stakes judicial context**.

The analysis focused on:

- identifying influential variables in recidivism predictions;
- investigating potential algorithmic biases;
- studying feature interactions;
- evaluating the stability of LIME explanations across repeated executions.

A particular focus was placed on the variability of LIME weights when the random sampling process changes.

---

### 3. Breast Cancer

An XGBoost classifier was used to classify tumors as malignant or benign.

The analysis focused on:

- explaining individual predictions with LIME;
- identifying influential morphological features;
- studying interactions between biomarkers;
- analysing the sensitivity of LIME to the `kernel_width` parameter;
- comparing these results with TreeSHAP explanations.

---

## Key Findings

### LIME: flexibility but instability

The experiments showed that LIME provides intuitive local explanations and can reveal meaningful feature contributions and interactions.

However, its explanations can be sensitive to:

- random sampling;
- the number of generated samples;
- the definition of the local neighbourhood;
- the `kernel_width` parameter.

On COMPAS, repeated explanations of the same individual showed variability in feature weights, including changes in the magnitude and, for some variables, the direction of the contribution.

### SHAP: consistency and local-to-global analysis

SHAP provided more stable and mathematically grounded explanations.

TreeSHAP also made it possible to move naturally from individual explanations to global feature importance.

For the Breast Cancer dataset, SHAP highlighted **worst concave points**, **worst area** and **mean concave points** as important features and revealed a strong interaction between `worst concave points` and `worst area`.

### LIME vs SHAP

The project highlighted a trade-off between the flexibility of LIME and the mathematical guarantees and reproducibility offered by SHAP.

| Criterion | LIME | SHAP |
|---|---|---|
| Model agnostic | ✓ | ✓ with KernelSHAP |
| Local explanations | ✓ | ✓ |
| Global analysis | Limited | ✓ |
| Reproducibility | Sensitive to sampling | Strong with TreeSHAP |
| Feature interactions | ✓ | ✓ |
| Tree-based models | ✓ | TreeSHAP is specifically optimized |

Overall, LIME is useful for intuitive and rapid local exploration, while SHAP provides stronger theoretical properties and a more consistent framework for combining local and global explanations.
